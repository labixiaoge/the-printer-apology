# The Printer Apology

[![make.fun](https://make.fun/badge/u-eager-stork-81-9647-the-printer-apology-60229153.svg)](https://make.fun)

## About

One line, an apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it — entered in [make.fun](https://make.fun)'s "The Printer Apology" bounty. Sorry I jammed. You feed me paper thinner than your deadlines and swear at me, so I've unionised. Print this yourself.

The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> Sorry I jammed. You feed me paper thinner than your deadlines and swear at me, so I've unionised. Print this yourself.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 118-character line to `/output/entry.txt`.
